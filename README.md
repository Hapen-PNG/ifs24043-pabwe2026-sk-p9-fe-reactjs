# TodoList Pro Frontend

## Deploy ke Vercel

Di Vercel, buka **Settings > Environment Variables** dan tambahkan
`VITE_API_BASE_URL` dengan URL backend Anda, misalnya
`https://alamat-backend-anda.com`. Setelah menyimpan, lakukan **Redeploy**
agar perubahan environment variable diterapkan.

Backend harus dapat diakses melalui HTTPS.
